# Service Pricing & Packages

## Starter Plan

**Best for:** Single-screen restaurants, food trucks, small cafes

| Item | Detail |
|------|--------|
| Screens | 1 |
| Layouts | 1 menu layout |
| Updates | Remote menu updates |
| Monitoring | Basic uptime monitoring |
| Support | Email support, next-business-day |

**Pricing:**
- Setup: $500 – $1,000
- Monthly: $75 – $125

**Setup includes:**
- 1 mini PC configured and shipped (or installed on-site)
- Menu layout designed from client assets
- CMS account created
- Display registered and scheduled

---

## Restaurant Plan

**Best for:** Sit-down restaurants with multiple screens

| Item | Detail |
|------|--------|
| Screens | 2 – 4 |
| Layouts | Food menu, drink menu, specials/promos |
| Updates | Remote menu updates |
| Scheduling | Time-based layout switching (lunch/dinner/happy hour) |
| Monitoring | Uptime + display status |
| Support | Email + phone, same-day response |

**Pricing:**
- Setup: $1,000 – $2,500
- Monthly: $150 – $300

**Setup includes:**
- 2-4 mini PCs configured and installed
- Multiple menu layouts designed
- Scheduled content rotation
- Staff training on requesting updates

---

## Multi-Location Plan

**Best for:** Restaurant groups, franchises, chains

| Item | Detail |
|------|--------|
| Locations | 2+ |
| Screens | Varies per location |
| Control | Centralized content management |
| Updates | Location-specific pricing/menus |
| Campaigns | Seasonal/holiday promos across all locations |
| Monitoring | Full monitoring with offline alerts |
| Support | Priority support, 4-hour response SLA |
| Reporting | Monthly display uptime report |

**Pricing:**
- Setup: Custom quote
- Monthly: $100 – $300 per location
